CORAL KEY HEAT is an original open-world crime game built for the Make GTA 6 bounty on make.fun. You prowl a sunlit island city of marinas, causeways and neon strips across a 15-mission campaign: steal cars, run cargo, dodge roadblocks and outfly a 5-star wanted response with air support overhead, while a live dispatch feed narrates the chase. Between jobs you spend your take in shops, grow your economy, check the full city map and review your record on the pause stats screen.

This entry competes in the bounty at https://make.fun/bounty/gta6-01 — an original city, original characters and an original story, made for the [Make GTA 6](https://make.fun/bounty/gta6-01) bounty on [make.fun](https://make.fun).

## Play

Run `node serve.ts`, then open http://localhost:8080 in a desktop browser. The game is static files under `game/`, played with keyboard and mouse, with no build step and no network requests.

## Hand-in

Run `node main.ts`: it copies `game/` and `screenshots/` into the output directory and writes `dossier.json` there, built with `buildDossier` from `vendor/makefun-game.ts`.
